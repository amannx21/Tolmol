# Code of conduct

Tolmol is about people who are often not listened to. We expect the same respect inside the project.

- Be kind and patient, especially with people writing in Hindi or in their second language.
- Criticise code, data and ideas, never people.
- Never post a real person's name, phone number, Aadhaar, ration card number or address in an issue, pull request,
  test or Arkiv entity. Use synthetic data only (`SYN-…` shop IDs, test cards).
- Never accuse a real ration dealer or shop by name. The demo shops are fictional.
- No harassment, threats or discrimination of any kind.

Report a problem to the maintainer through GitHub (https://github.com/amannx21) or by opening a private security
advisory (see [SECURITY.md](SECURITY.md)). The maintainer may edit or remove content and block people who break these
rules. This code is adapted in spirit from the Contributor Covenant 2.1.
